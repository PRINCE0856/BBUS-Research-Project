--- PART 4: the vulnerability interaction (the triple-difference coefficient) ---
A subgroup-difference test needs roughly 4x the sample of a main effect for the same MDE,
so the detectable interaction is about 2x the main-effect MDE.

  Group A pooled main effect (ICC 0.05):        6.4 pp
  Group A pooled VI interaction, approx:        12.7 pp
  Group B DiD main effect (ICC 0.05, r=0.7):    5.0 pp
  Group B DiD VI interaction, approx:           10.0 pp
